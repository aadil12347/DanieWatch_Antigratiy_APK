# CinemaOS.tech Extraction Guide

This document explains how `cinemaos.tech` fetches and serves its video streams and subtitles. This information is derived from captured network traffic (`download.json`) and can be used to build a video extractor in Dart/Flutter.

## 1. The Main Provider API

When a movie page loads (e.g., `https://cinemaos.tech/movie/watch/454639`), the site hits its internal provider API to retrieve streaming sources.

**Endpoint:**
```http
GET https://cinemaos.tech/api/providerv4?type=movie&tmdbId=454639&imdbId=tt0427340&t=Masters+of+the+Universe&ry=2026&secret={SECRET_TOKEN}&_gt={GT_TOKEN}
```

- **tmdbId / imdbId**: Identifiers for the media.
- **secret & _gt**: These are cryptographic tokens likely generated by obfuscated JavaScript on the page. Generating these manually requires reverse-engineering their hashing algorithm.

## 2. Stream URLs and Cloudflare Proxies

The API returns streaming URLs that are masked behind Cloudflare Worker proxies. The site uses these proxies to bypass CORS restrictions and hide the actual video hosts.

### A. M3U8 (HLS Streams)
The site requests an HLS stream via a proxy:
```
https://play.cinemaos.workers.dev/api/proxy?url=https%3A%2F%2Fcdn.1shows.app%2Fe%2FDBkXNgRLUFRZRVJP%2Fmaster.m3u8&referer=https%3A%2F%2Fplayer.vidzee.wtf%2F
```

If we URL-decode the `url` parameter, the **actual raw streaming URL** is:
👉 `https://cdn.1shows.app/e/DBkXNgRLUFRZRVJP/master.m3u8`

### B. MP4 (Direct Media)
The site also requests direct MP4 files via a different proxy:
```
https://raindrop.tagstream.workers.dev/mp4-proxy?url=https%3A%2F%2Fbcdnxw.hakunaymatata.com%2Fresource%2F7663418c6f6e03f1ba25eafedb3d3d9d.mp4%3Fsign%3Dbbcb52a98647efa60af38659e5f849af%26t%3D1780658621&referer=https://fmoviesunblocked.net/&origin=https://fmoviesunblocked.net
```

Decoded, the **actual raw MP4 URL** is:
👉 `https://bcdnxw.hakunaymatata.com/resource/7663418c6f6e03f1ba25eafedb3d3d9d.mp4?sign=bbcb52a98647efa60af38659e5f849af&t=1780658621`

## 3. Subtitles
Subtitles are fetched directly from an OpenSubtitles proxy:
```http
GET https://cinemaos.tech/api/subtitles/opensubtitles?imdbId=tt0427340
```

## How to Implement in Flutter (`videasy_extractor.dart`)

You have two primary approaches for implementing this extractor:

### Approach 1: The WebView Interception Method (Recommended & Easiest)
Because generating the `secret` and `_gt` tokens requires reverse-engineering complex JavaScript, the most reliable method is to use a headless `InAppWebView`.

1. Load the `cinemaos.tech/movie/watch/{id}` URL in an invisible `InAppWebView`.
2. Use `onLoadResource` or `shouldInterceptAjaxRequest`.
3. Look for any URL containing:
   - `.workers.dev/api/proxy?url=`
   - `mp4-proxy?url=`
   - `.m3u8`
   - `.mp4`
4. Once you intercept one of these URLs, extract the `url=` parameter and URL-decode it (`Uri.decodeFull()`).
5. You now have the direct stream link! Close the WebView and return the link to the video player.

### Approach 2: The API Reverse-Engineering Method (Harder but Faster)
1. Write a script to download the main `cinemaos.tech` HTML and JavaScript.
2. Find the function that generates `secret` and `_gt`.
3. Emulate that logic in Dart (e.g., using a JS engine like `flutter_js` or translating it to Dart cryptography functions).
4. Make a direct HTTP GET request to `/api/providerv4`.
5. Parse the returned JSON for the proxy URLs, decode them, and extract the raw streams.
